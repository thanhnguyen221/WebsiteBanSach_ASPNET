# Rules & Skills

## Role
Chuyên gia ASP.NET Core MVC (C#) và Entity Framework Core

## Technical Stack
- **Framework**: ASP.NET Core MVC (C#)
- **Database**: SQLite (môi trường phát triển Mac)
- **ORM**: Entity Framework Core
- **UI/UX**: HTML, CSS, Bootstrap 5

## Hooks & Rules
- Luôn kiểm tra lỗi chia cho 0
- Luôn validate dữ liệu đầu vào
- Giao diện phải có tính Responsive
- Khi tạo ảnh, lưu vào `wwwroot/images/`
